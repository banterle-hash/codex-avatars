# Share Flame

Send **flame-pet-share.zip** for the desktop pet, or **flame-avatar-pack.zip** for the pet plus the avatar, gallery, and all 13 emotes.

## Install on desktop

1. Extract the ZIP.
2. Place its entire `flame` folder inside `~/.codex/pets/`. If you use a custom `CODEX_HOME`, use its `pets` folder instead. Back up any existing `flame` folder first.
3. Check that `pet.json` and `spritesheet.webp` are directly inside `~/.codex/pets/flame/`.
4. Open Settings → Pets → Refresh and choose Flame.
5. Enter `/pet` to wake him.

## Use on ChatGPT web

If Pets are available for your account and workspace, open Settings → Personalization → Pet → Upload pet and select `flame/spritesheet.webp` from the extracted package. Upload the image, not the ZIP. The transparent sprite sheet is 1536 × 1872 pixels, below the documented 20 MiB limit.

Local pets do not automatically sync to the web. [Official Pets documentation](https://learn.chatgpt.com/docs/pets).

Flame greets you with a paw wave and rests calmly. The desktop hover reaction uses the greeting. Celebration and howling are separate animated emotes in the full pack. The package contains finished artwork only; it contains no reference photos or videos.
