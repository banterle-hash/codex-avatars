# Flame v3

Flame v3 is the stable desktop pet package. It retains the established animation set and adds the reviewed v3 breathing-and-blinking idle, paw greeting, and a complete 16-pose seated look loop.

Install by extracting `flame-v3.zip` and copying the enclosed `flame` directory to `~/.codex/pets/`. In Codex, choose **Settings → Pets → Refresh**, then select Flame.

`flame/pet.json` and `flame/spritesheet.webp` are the installable files. The adjacent validation and QA files document the release checks.
